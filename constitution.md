# Constituição do Projeto

1. Use Python 3.14+ e pytest para todos os testes.
2. Mantenha o código simples e sem dependências externas desnecessárias.
3. Toda função de negócio deve referenciar, em comentário, a cláusula EARS que implementa (ex.: # REQ-01).
4. Nenhum código entra no repositório sem cláusula correspondente em specs/.
5. Toda mudança de regra começa na spec; spec, testes e código mudam no mesmo commit.
